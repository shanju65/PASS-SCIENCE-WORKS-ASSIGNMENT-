# Data Provenance

`example_temperature.csv`
- Synthetic ANSYS-style nodal-temperature sample created for this project.
- Contains node coordinates in metres and temperatures in degrees Celsius.
- Schema: `node_id,x_m,y_m,z_m,temperature_C`.
- No personal, credential, machine-generated identity, or third-party confidential data is present.

`example_geometry.stl`
- Self-created ASCII triangular-prism/geometry sample included for parser and 3D viewer testing.
- Validation coverage: finite coordinates and normals, closed triangular facets, positive surface area.
