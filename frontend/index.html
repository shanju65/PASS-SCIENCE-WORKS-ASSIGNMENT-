Analytical Solution & FE Formulation Notes

1. Exact Closed-Form Reference Solution

Integrating -k A T''(x) = q A twice with boundaries T(0)=100°C and T(1)=20°C yields:

T_exact(x) = 100 - 80·(x/L) + [q / (2·k)] · x · (L - x)

2. Element Stiffness Matrix & Load Vector

Ke = (k·A / le) * [  1, -1 ]
                  [ -1,  1 ]

Fe = (q·A·le / 2) * [ 1, 1 ]^T

3. Genuine Debugging Insight

Midpoint Interpolation Insight: In 1D linear elements with uniform heat generation, nodal FEA values match the exact analytical values almost exactly due to the green's function superconvergence. However, evaluating errors at the element midpoints using shape functions T_mid = 0.5(T_i + T_{i+1}) reveals the true quadratic discretization error e(h) = q·le² / (8k), which exhibits exact quadratic convergence O(h²) (halving element size reduces midpoint error by exactly a factor of 4).

Why JTAG is a Debug Interface (Not a Compute Board)

1. Asymmetric Master/Target Topology: JTAG (IEEE 1149.1) is an instrumentation bus designed to control state machines (TAP controllers) for boundary scan and processor halting. It does not carry peer-to-peer compute protocols.

2. Signal Ownership Contention: The debug probe actively drives TCK, TMS, and TDI. Microcontrollers and FPGAs are targets that listen on those pins and drive TDO only during shift states. Connecting two masters directly creates destructive electrical bus contention.

3. Dynamic Voltage Level Shifting: Target boards run at diverse internal I/O voltages (e.g. 1.8V vs 3.3V). The JTAG probe uses an active VTref sense pin to dynamically level-shift its output drivers, avoiding latch-up or gate oxide breakdown.

Manual Chain-Rule Derivations & Explanation

Loss: J = 0.5 · (y_hat - y)²
dJ / dy_hat = (y_hat - y) = 0.4621 - 2.0 = -1.5379

dJ / dv = (y_hat - y) · h = (-1.5379) · 0.4621 = -0.7107
dJ / dc = (y_hat - y) = -1.5379

dJ / dh = (y_hat - y) · v = -1.5379
dh / dz = 1 - tanh²(z) = 1 - (0.4621)² = 0.7864
dJ / dz = (-1.5379) · (0.7864) = -1.2095

dJ / dw = (dJ / dz) · x = -1.2095
dJ / db = (dJ / dz) · 1 = -1.2095

Gradient Direction: Because y_hat < y, the residual error is negative, making all partial derivatives negative. Gradient descent subtracts η · grad, thereby adding positive increments to all weights and driving y_hat towards 2.0.
